## 🎯 班親會現場使用方式

### 1. 【最強推薦】全螢幕網頁簡報模式
* 在資料夾中直接雙擊打開 **`全螢幕簡報.html`**（或開啟 `website/presentation.html`）。
* **鍵盤操作快捷鍵**：
  * **下一頁**：按鍵盤 **`→`（右方向鍵）**、**`Space`（空白鍵）**、**`Enter`** 或 **`PageDown`**
  * **上一頁**：按鍵盤 **`←`（左方向鍵）**、**`Backspace`** 或 **`PageUp`**
  * **全螢幕切換**：按鍵盤 **`F`** 鍵（或點右上角 `⛶ 全螢幕` 按鈕）
  * **講稿提示開關**：按鍵盤 **`N`** 鍵（底部滑出即時講者提詞卡，不怕忘詞！）
  * **滑鼠點擊**：點畫面右側區域翻下一頁，點畫面左側區域翻上一頁。
  * **首頁 / 尾頁**：按 **`Home`** 回到第 1 頁，按 **`End`** 跳到第 24 頁。
* **畫面無干擾**：滑鼠停止移動 3.5 秒後，所有控制列自動淡出隱藏；滑鼠晃動即刻喚醒。

### 2. 一般投影模式
* 亦可直接開啟 `slides/` 資料夾輪播圖片，或插入 PowerPoint / Keynote 放映。

### 3. 開場暖場影片
* 在班親會開始前或家長陸續進場入座時，可先投影播放：
  `宣導資料\開場-輔導室宣導影片(班親會暖場).mp4`
  營造溫馨感人的共鳴氛圍，隨後切換至 Slide 01 正式開場。

### 4. 演講備忘指南（講者備註）
* 開啟 `speaker-notes.md`，每一頁均規劃了：
  * 畫面重點文字
  * **老師可以說**（口語化、有溫度、兼具教育專業的自然講法）
  * **建議時間**（共 30 分鐘，精準分配時間與節奏）

### 5. 家長手機網站
* 開啟 `website/index.html`。
* 此網站採 **Mobile-First（手機優先）** 響應式設計，家長回家後可以用手機隨時瀏覽、轉傳給另一半或長輩。
* 包含：
  * 導師理念與 3C 觀點
  * SEL 五大步驟與臺中市「愛閱家庭」雲端智慧存摺登錄資訊（115.09.16 - 10.25）
  * 學務處請假規定、通報專線與臨時外出校園安全管制
  * 畢業專案進度、班親會長與總務角色說明、三大財務透明承諾、家長委員會委員致謝
  * 親師聯繫管道（平時 LINE、緊急專線電話 `0963-159-896` 點擊直撥）
  * 常見問題 FAQ 手風琴互動展示
